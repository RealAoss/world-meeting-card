# World Meeting Card

Convert a single UTC meeting time into local dates and times for a team, including daylight-saving offsets.

## Open the app

Download `index.html` and open it in a modern browser. Everything runs locally. Work stays in the tab until you close it.

## Example

Try 2026-01-15 at 23:00 UTC with Asia/Tokyo. The card shows 08:00 on January 16 in Tokyo. The browser supplies time-zone rules. Download the result as plain text.

## Limitations

Work stays in the browser tab. Save the result before closing or refreshing the page.
